# 개선 효과 검증 결과

결론: **에셋 찾기(순위)는 기존 방식보다 확실히 나아졌습니다.** 한국어 질의 10개 중 9개에서 정답이 상위 5위 안에 왔고, 지금 방식인 이름 검색은 영어로도 10개 중 5개였습니다. **"없는 물건"을 가르는 일은 근거가 약합니다.** 임계값 구간이 같은 데이터로 사후에 구한 매우 좁은 범위에서만 나왔습니다.

- 원자료: [`results/20261117_171146/`](../results/20261117_171146/summary.md) (2026-11-17)
- 성공 기준과 정답표: [문제 정의서](PROBLEM_DEFINITION.md) (모델 실행 전 확정)
- 모델 후보 비교: [모델 선정 근거](MODEL_SELECTION.md)

## 1. 검증 방법

정량 방식으로 쟀습니다. 질의 13건(정답 있음 10건, 없는 물건 3건)을 한국어와 영어로 각각 넣고, 두 방식을 같은 기준으로 채점했습니다.

- **기존 방식(기준선):** 콘텐츠 브라우저 이름 검색을 흉내 냈습니다. 질의 단어와 에셋 이름의 `_` 토큰이 겹치는 수로 정렬하고, 겹치는 단어가 없으면 결과가 없습니다. 이름이 영어라 한국어 질의로는 잴 수 없습니다.
- **PoC:** SigLIP 2로 썸네일과 질의를 비교한 점수순 목록입니다.
- **채점:** 정답이 상위 5위 안에 있으면 통과입니다. 상위 5위 안의 함정(헷갈리기 쉬운 오답) 수도 셉니다. 없는 물건 질의는 1위 점수를 봅니다.

전체 자릿수는 원자료 `summary.md`에 있습니다.

## 3. 질의별 비교

첫 정답 순위가 작을수록 좋습니다. "결과 없음"은 이름 검색에서 겹치는 단어가 하나도 없었다는 뜻입니다.

| id | 질의 (한국어 / 영어) | 이름 검색: 결과 수 → 첫 정답 순위 | PoC 한국어: 첫 정답 순위 | PoC 영어: 첫 정답 순위 | 판정 |
| --- | --- | --- | --- | --- | --- |
| q01 | 등불 / lantern | 4 → 1위 | 1위 | 1위 | 둘 다 통과 |
| q02 | 노점 천막 / market stall | 2 → 1위 | 3위 | 2위 | 둘 다 통과, 이름 검색이 더 앞 |
| q03 | 폭포 / waterfall | 1 → 1위 | 2위 | 1위 | 둘 다 통과 |
| q04 | 짚으로 엮은 지붕 / straw roof | 47 → 33위 | 52위 | 53위 | **둘 다 실패** |
| q05 | 사람 모양 돌 조각 / stone figure of a person | 2 → 정답 없음 | 5위 | 3위 | **PoC만 통과** |
| q06 | 아치형 출입구 / arched gateway | 결과 없음 | 3위 | 2위 | **PoC만 통과** |
| q07 | 늘어진 천 깃발 / hanging cloth banner | 2 → 1위 | 1위 | 1위 | 둘 다 통과 |
| q08 | 꽃이 심긴 화분 / planter with flowers | 1 → 정답 없음 | 2위 | 1위 | **PoC만 통과** (함정 포함) |
| q09 | 길가에 세운 가로등 / street lamp post | 결과 없음 | 1위 | 1위 | **PoC만 통과** |
| q10 | 나무 울타리 / wooden fence | 26 → 1위 | 1위 | 1위 | 둘 다 통과 |

정리하면 PoC만 통과한 질의가 4개, 이름 검색만 통과한 질의는 0개, 둘 다 실패한 질의가 1개입니다.

## 4. 나란히 본 사례 (정성)

**이름 검색으로는 못 찾고 PoC는 찾은 경우**

- **q09 "길가에 세운 가로등":** 이름이 `SM_lamppost_03`이라 "street lamp post"는 단어가 하나도 겹치지 않아 결과가 0건입니다. PoC는 한국어 문장으로 `SM_lamppost_03`을 1위, `SM_lamppost_01`을 2위로 찾았습니다.
- **q06 "아치형 출입구":** 이름은 `SM_wall_arch_01`이라 "arched"와 "arch"가 다른 단어로 처리되어 결과가 0건입니다. PoC는 3위에서 찾았습니다.
- **q05 "사람 모양 돌 조각":** 이름 검색은 "stone"이 겹치는 `SM_stone_flower_bed_01·02`(꽃밭)만 내놓았습니다. PoC는 이름에 단어가 없는 `SM_statue_01`을 5위에서 찾았습니다. 다만 그 위 1~4위는 절벽(`SM_cliff_*`)과 기둥이었습니다.

**이름 검색이 더 나은 경우**

- **q02 "노점 천막":** 이름 `SM_market_tent_01`에 "market"이 있어 이름 검색은 1위로 찾았습니다. PoC는 지붕 모서리(`SM_roof_corner_*`) 두 개 다음인 3위였습니다.

| 사례 | 무슨 일이 있었나 | 원인 |

| 없는 물건 (피자·자동차·컴퓨터) | 언제나 무언가를 1위로 내놓음. "자동차/car"의 1·2위가 초가지붕(`SM_thatched_roof_03·04`), "피자"의 1위가 초가지붕 벽 | 순위 방식이라 항상 결과가 나옴. 점수는 낮지만(최대 0.00031), 약한 정답 점수와 겹침. 초가지붕이 엉뚱한 질의에 자주 끌려오는 이유는 확인 못 함 |

| q03 "폭포" (한국어) | 하늘 돔(`SM_sky`)이 1위, 폭포가 2위 | 확인 못 함. 폭포 썸네일은 물 흐름 애니메이션 때문에 유일하게 그림이 안정되지 않은 채 저장된 것(`manifest.csv`의 `note`) |
| 한국어 임계값 | 정답이 남는 구간이 0.000229 < t ≤ 0.000261로, 위아래 1.14배뿐 | 한국어 점수가 영어보다 대체로 10배 이상 낮음(등불 0.045 vs lantern 0.548) |

## 6. 재현 방법

- **채점만 다시 하기:** 색인(`index.npz`)이 있으면 README의 4단계 명령으로 다시 채점할 수 있습니다. `tests/test_regression.py`가 커밋된 결과 26행이 지금 코드로 그대로 나오는지 확인합니다.
- **처음부터 하기:** 1단계(썸네일) → 2단계(색인) → 4단계(채점) 순서로 실행합니다. 썸네일 조건은 `thumbs/CONDITIONS.md`에 있고, 같은 조건으로 다시 찍으면 픽셀까지 같게 나오는 것을 에디터 통합 테스트로 확인했습니다.
- **한계:** 에셋 팩과 썸네일은 재배포 금지라 저장소에 없습니다. 그래서 평가자가 이 숫자를 그대로 다시 내려면 같은 에셋 팩이 필요합니다. 코드는 폴더 경로와 접두사를 인자로 받으므로, 다른 UE 프로젝트의 에셋과 자기 정답표로는 바로 돌릴 수 있습니다.
