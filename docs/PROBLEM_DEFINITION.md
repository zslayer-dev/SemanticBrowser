# 문제 정의서 — 게임 에셋을 한국어 문장으로 찾기

작성: 2026-11-17 (성공 기준은 모델 실행 전에 확정, 커밋 `095c745`) · 정리: 2026-11-18

## 1. 도메인

**Unreal Engine 5로 게임을 만들 때 3D 에셋을 찾아 배치하는 일**입니다.

게임 레벨(맵)은 건물, 벽, 지붕, 소품, 나무 같은 3D 부품 파일(에셋)을 하나씩 골라 배치해서 만듭니다. 에셋은 직접 만들기보다 Fab(구 Unreal Marketplace) 같은 곳에서 팩 단위로 사서 쓰는 경우가 많습니다. 팩 하나에 수십에서 수백 개가 들어 있고, 프로젝트에는 여러 팩이 쌓입니다.

이 PoC의 대상은 Lyra 기반 프로젝트(LyraRPG)에 들어 있는 동양풍 마을 팩 `Content/Asian_Village`의 StaticMesh 243개입니다.

## 2. 현재의 문제

**지금 방식:** 에디터의 콘텐츠 브라우저에서 **파일 이름으로 검색**하거나, 폴더를 열어 **썸네일을 눈으로 넘겨** 찾습니다.

**번거로운 점**

- **이름은 만든 사람의 규칙을 따릅니다.** 같은 물건도 팩마다 이름이 다릅니다. "가로등"은 이 팩에서 `SM_lamppost_03`, "아치형 출입구"는 `SM_wall_arch_01`, "꽃 화분"은 `SM_flower_box_01`입니다. 이름 규칙을 모르면 검색어를 맞히기 어렵습니다.
- **한국어로는 검색할 수 없습니다.** 파일 이름이 전부 영어라서 "등불", "폭포"를 입력하면 아무것도 나오지 않습니다.
- **생김새로 찾으려면 눈으로 넘겨야 합니다.** "짚으로 엮은 지붕", "사람 모양 돌 조각"처럼 모양은 알지만 이름을 모르는 경우, 폴더를 하나씩 열어 썸네일을 훑어야 합니다. 팩이 늘어날수록 이 시간이 늘어납니다.
- **비슷한 것끼리 헷갈립니다.** 등불(`lantern`)과 가로등(`lamppost`), 나무 울타리와 돌 울타리처럼 이름이나 모양이 비슷한 에셋이 섞여 있습니다.

**측정한 것과 측정하지 못한 것:** 이름 검색으로 정답을 찾는 비율은 쟀습니다(영어 질의 10개 중 5개, 아래 성공 기준과 같은 방식). 사람이 썸네일을 넘겨 찾는 데 걸리는 시간은 재지 않았습니다.

## 3. 개선 가설

> 에셋마다 같은 조건으로 찍은 썸네일을, 그림과 문장을 함께 이해하는 AI 모델로 숫자 벡터(임베딩)로 바꿔 두면, 한국어 문장으로 생김새가 맞는 에셋을 찾을 수 있다. 이름 검색으로 못 찾는 질의도 찾을 수 있다.

AI가 들어가는 단계는 다음과 같습니다.

1. **색인(한 번):** UE 에디터에서 에셋마다 썸네일을 같은 조건으로 렌더링 → 이미지 임베딩으로 변환해 저장
2. **검색(질의마다):** 한국어 문장 → 텍스트 임베딩 → 이미지 임베딩과 유사도 계산 → 점수순 후보 목록
3. **에디터 연결:** 결과 에셋을 콘텐츠 브라우저에서 바로 선택

추가 가설로, 점수에 임계값을 걸면 **프로젝트에 없는 물건을 물었을 때 "없음"이라고 답할 수 있다**고 보았습니다. 담당자가 "가장 비슷한 것"을 "찾던 것"으로 착각하지 않게 하기 위해서입니다.

## 4. 대상 사용자

- **레벨 디자이너·환경 아티스트:** 레벨을 꾸미며 하루에도 여러 번 에셋을 찾습니다. 가장 직접적으로 도움을 받습니다.
- **에셋 팩을 처음 받은 사람:** 팩의 이름 규칙을 모르는 상태라 이름 검색이 특히 잘 안 됩니다.
- **기획자 등 영어 이름에 익숙하지 않은 사람:** 한국어로 바로 찾을 수 있습니다.

## 5. 성공 기준 (모델 실행 전에 확정, 변경하지 않음)

1. 정답이 있는 질의 10건 중 **8건 이상**에서, 정답 집합 중 하나가 **상위 5위 안**에 온다. 한국어 질의 기준이고, 영어 질의는 비교용으로 따로 집계한다.
2. 프로젝트에 없는 것을 묻는 질의(absent) **3건**에서는, 임계값을 적용하면 결과가 **비어야** 한다.

**정답표:** [`answer_key.csv`](../answer_key.csv)에 있습니다. 질의 13건(정답 있음 10건, 없음 3건)이고, 그중 3건은 일부러 어려운 질의(`hard`)로 넣었습니다. 헷갈리기 쉬운 오답(`traps`)도 함께 적었습니다. 모두 콘텐츠 브라우저 썸네일을 직접 보고 모델 실행 전에 확정했습니다.

**기준선(지금 방식):** 같은 질의로 이름 검색을 흉내 내 같은 기준으로 채점합니다. 질의 단어와 에셋 이름 토큰이 겹치는 수로 정렬합니다.

## 6. 제약

- **에셋을 외부로 보내지 않습니다.** 구매한 에셋이라, 모델은 로컬 CPU에서만 돌립니다. 외부 API 서비스는 후보에서 제외했습니다.
- **에셋과 썸네일 묶음은 저장소에 올리지 않습니다.** 재배포가 금지된 콘텐츠이기 때문입니다. 렌더 이미지(스크린샷)는 약관이 배포를 허용하므로 README에 넣었습니다.
- **모델 라이선스는 상업 사용이 가능해야 합니다.**
